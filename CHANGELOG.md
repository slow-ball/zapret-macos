# Изменения

## 1.0.0

Первый выпуск zapret для macOS как отдельного приложения со своим движком.

- **Адаптивная стратегия.** Лестница приёмов прямо в движке: у каждого сайта свой приём, при обрыве сайт
  сразу переходит на следующий. Отдельные лестницы для QUIC и голоса Discord
- **Подбор в реальном времени.** Движок мерит скорость, которую получает браузер, пробует другие приёмы
  на части соединений и переводит сайт на заметно более быстрый. У серверов видео YouTube — своя ступень
  у каждой группы
- **Учится сам.** Раз в сутки лучший приём становится первым, неудачные заменяет генератор новыми
- **Умный режим.** Обрабатываются только сайты, которые без обхода не открываются; движок видит сбросы
  и подмену страниц провайдером по входящим пакетам
- **Свой прокси для Telegram** — без Python: веб-серверы Telegram, посредники на Cloudflare, напрямую
- **Свои фейковые пакеты** — ClientHello, QUIC Initial и STUN собираются из исходников проекта
- **DNS для нейросетей**, проверка сайтов «Сайт не открывается?», глубокий подбор, игровой фильтр
- **Приложение**: главная, стратегии, страница «Адаптация», сайты, проверка, журнал, настройки; панель
  в строке меню, виджет, ⌃⌥Z
- **Сам следит за собой**: автопочинка, ежедневные свежие стратегии, обновления только подписанными версиями
