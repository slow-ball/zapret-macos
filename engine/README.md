# Движок zapret-macos

Два бинарника, оба собирает `build/utunws.sh` (Intel и Apple Silicon), оба проверяются в CI на каждом изменении.

- **`nfq/` → utunws** — движок обхода. Начало — маковский порт nfqws из [zapret](https://github.com/bol-van/zapret)
  (bol-van), сделанный [Flowseal](https://github.com/Flowseal/zapret-mac-discord-youtube): взят на коммите
  из `UPSTREAM` и дальше развивается здесь. Лицензия MIT — `LICENSE`. Наш код отмечен комментариями
  `zapret-macos:`, новые файлы — `ladder.*` и `macrecv.*`.
- **`tg/` → zapret-tg** — прокси для Telegram, целиком свой (Swift, без зависимостей).

## Что своего в utunws

- **Лестница приёмов** (`ladder.c`, `--ladder`, `--ladder-state`): адаптивная стратегия. Профиль на каждый
  приём, у каждого сайта — свой. Сбой (сброс, переадресация на заглушку, тишина) поднимает сайт на следующий
  приём, ступени сайтов хранятся в файле. Три лестницы: TCP, QUIC и голос Discord. Сайт — два последних
  уровня имени, кроме зон вида co.uk и общих хостингов; у серверов видео YouTube ключ — их группа (`sn-…`).
- **Живой выбор** (`ladder_sample`, `ladder_pick`): скорость сайта — по подтверждениям браузера за активное
  время, средняя по каждому приёму. Медленный сайт пробует другие приёмы на каждом 8-м соединении, быстрый —
  на 50-м; заметно более быстрый приём (в 1,5 раза, по трём замерам) становится его собственным.
- **Статистика приёмов и сайтов** (`--ladder-stats`, `--ladder-seen`): по ней скрипт учит порядок лестницы
  и заменяет неудачные приёмы новыми. Правку файла скриптом движок не затирает: файл, изменённый после
  последнего чтения, он оставляет как есть и читает при следующем запуске.
- **QUIC и голос по пакетам клиента**: повтор рукопожатия QUIC или запроса адреса без ответа — сбой.
- **Входящие пакеты** (`macrecv.c`): порт видит только исходящие пакеты из utun. Движок читает из основной
  сети ответы серверов на установку соединения, сбросы и первые HTTP-ответы — так автосписок nfqws (умный
  режим) и лестница видят, что провайдер оборвал сайт. IPv4 и IPv6, включается `ZAPRET_INBOUND=1`.
- **`--drop`**: профиль, который ничего не пропускает (QUIC к серверам видео, чтобы браузер сразу шёл по TCP).
- Конфиг до 1 МБ (лестница даёт длинные конфиги), выученное сохраняется при остановке.

## zapret-tg

- `serve <порт> <секрет>` — MTProto-прокси для Telegram Desktop (obfuscated2, секрет `dd`). До Telegram:
  WebSocket к его веб-серверам (`kwsN.web.telegram.org`, по адресу с именем внутри TLS — подмена DNS не мешает),
  затем посредники сообщества на Cloudflare (список — `cf-domains.txt` рядом, встроенный — запасной), затем
  напрямую к дата-центру. Протокол — как у tg-ws-proxy от Flowseal, написан заново.
- `check <хост> <порт> <секрет> [dc]` — рукопожатие как у Telegram Desktop и первый запрос авторизации.
- `stun` — запрос STUN, как у голоса Discord: проверка, что UDP-путь работает.
