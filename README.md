## Что это

Провайдер замедляет и рвёт соединения, глядя на имя сайта в первых пакетах. zapret меняет эти пакеты
так, что фильтр провайдера их не понимает, а сайт — понимает. VPN не нужен: трафик идёт напрямую,
без сторонних серверов и без потери скорости.

Включается одной кнопкой — в строке меню, в виджете или <kbd>⌃⌥Z</kbd>. Дальше настраивать ничего не нужно.

## Чем он отличается

- **Подстраивается под каждый сайт.** Вместо одной общей настройки — лестница приёмов прямо в движке.
  Провайдер оборвал сайт — движок сразу переводит его на следующий приём и запоминает тот, что сработал.
  Отдельно для обычных сайтов, для QUIC и для голоса в Discord.
- **Выбирает самый быстрый способ на ходу.** Движок мерит скорость, которую на деле получает браузер,
  иногда пробует другие приёмы на части соединений и переводит сайт на заметно более быстрый.
  У каждой группы серверов видео YouTube — свой приём.
- **Учится сам.** Раз в сутки приём, на котором остановилось больше всего сайтов, становится первым,
  а неудачные заменяются новыми — их генератор собирает из лучших.
- **Трогает только то, что заблокировано.** Обход получают YouTube, Discord, Telegram, ваши сайты,
  известные заблокированные сайты и те, что без обхода не открылись, — их движок находит сам. Остальной
  интернет, банки и Госуслуги идут как есть, ничего не ломается.
- **Свой прокси для Telegram.** Встроенный, включается одной кнопкой: напрямую через веб-серверы Telegram,
  а где их закрыли — через посредников сообщества на Cloudflare.
- **DNS для нейросетей** — для сервисов, которые сами закрыты для России. Включается только вручную.
- **Следит за собой.** Переживает смену Wi-Fi, сон, VPN и обновления macOS, сам чинится, свежие стратегии
  получает каждый день, обновляется без пароля — и только подписанными версиями.

## Установка

1. Скачать **[zapret.dmg](https://github.com/slow-ball/zapret-macos/releases/latest)** и перетащить zapret в «Программы».
2. Открыть zapret. Если macOS не даёт: **Системные настройки → Конфиденциальность и безопасность →
   «Всё равно открыть»** (один раз — почему, см. ниже).
3. Нажать **«Установить»** и ввести пароль от мака. Перезапустить браузер.

Через [Homebrew](https://brew.sh): `brew install --cask slow-ball/tap/zapret`

## Если что-то не открывается

**«Сайты» → «Сайт не открывается?»** — zapret за несколько секунд скажет, в чём дело: провайдер, DNS,
заблокированный адрес или сам сервис, — и подберёт способ именно для этого сайта. На странице
**«Адаптация»** видно, какой приём у каждого сайта и почему он менялся.

Не помогло — **«Проверка» → «Сообщить о проблеме»**: откроется готовый отчёт, IP-адреса и имена из него убраны.

## Вопросы

<details>
<summary>Можно вместе с VPN?</summary>

Да. Пока VPN включён, трафик идёт через него; выключите — zapret сразу продолжит работу.
</details>

<details>
<summary>Почему macOS не даёт открыть приложение?</summary>

Подпись Apple требует платный аккаунт на реальное имя, а проект анонимный. Приложение собирается открыто,
в GitHub Actions из этого репозитория. Разрешить открытие нужно один раз.
</details>

<details>
<summary>Это безопасно?</summary>

Всё, что zapret скачивает, проверяется: обновления — подписью ключа проекта, движок и приложение —
контрольными суммами, закреплёнными в коде. Приложение само сверяет установленные файлы с подписанным
релизом. Пароль нужен один раз — для правил файрвола macOS; дальше приложение управляет zapret без пароля,
но только фиксированным набором команд. Движок работает без прав root.

Прокси для Telegram ничего не расшифровывает: данные зашифрованы самим Telegram. DNS для нейросетей — это
сторонние бесплатные сервисы (WebShift DNS, DNS-AI): им видно, какие сайты вы открываете.
</details>

<details>
<summary>Тормозит ли интернет?</summary>

Нет. Движок трогает только первые пакеты соединения, остальное проходит как есть. Если провайдер
замедляет сам сервис целиком — по адресам, а не по имени сайта, — это никакой обход пакетов не снимет,
и zapret честно скажет об этом в «Сайт не открывается?».
</details>

<details>
<summary>Что и куда ставится, как удалить?</summary>

Приложение — в «Программы», папка проекта со своими списками сайтов — `~/zapret-macos`, служебная часть —
`/opt/zapret-macos` и службы `com.zapret-macos.*`. Удалить: **Настройки → «Удалить…»** — уберётся всё,
вместе с правилами файрвола.
</details>

<details>
<summary>Для продвинутых: Терминал</summary>

`~/zapret-macos/zapret.command` — меню, `~/zapret-macos/src/zapret.sh help` — все команды.
Как устроен проект и как его собрать — в [ARCHITECTURE.md](ARCHITECTURE.md).
</details>
